Private iPhone robotics prototype

Turn an iPhone into a tiny autonomous rover.

Mount an iPhone on a compact two-wheel robot. Drive it manually, teach it to follow a target, and run on-device vision without a cloud account. LiDAR is an optional enhancement; the base experience uses the camera.

Join the prototype test Read the validation brief

What the first build does

Drive

Use a phone joystick over BLE with a firmware-level timeout and stop path.

See

Process camera frames locally with Vision/Core ML. No cloud account required.

Learn

Compare phone pose, wheel odometry, and real-world course performance.

Prototype fit

This is for makers, iOS developers, and STEM learners who have an existing or spare iPhone. Hardware target: under $150 excluding the phone. Indoor, low-speed, supervised operation only.

LiDAR depth is available only on supported Pro-class devices; camera-only mode remains the baseline.
