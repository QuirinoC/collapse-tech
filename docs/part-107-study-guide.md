# Part 107 (UAG) study guide — Juan Quirino

Practical prep for the FAA **Remote Pilot Certificate** with a small UAS rating. Written for the [WA listing-media 90-day plan](./wa-listing-media-90-day-plan.md) (evenings **5–9pm** + weekends). This is a study aid, not legal advice; always verify against current FAA publications before you fly for pay.

**Last updated:** 2026-09-03.

---

## “170” vs Part 107

There is **no FAA drone airman certificate numbered “170.”** For commercial listing media, you want **14 CFR Part 107** and the knowledge test **Unmanned Aircraft General – Small (UAG)**.

Nearby “170” you may see in ag/spray reading: **40 CFR Part 170** is an **EPA** Worker Protection Standard for pesticides — irrelevant to the UAG exam and to stills/video listing work.

## Exam logistics

| Item | Current official / vendor fact |
| --- | --- |
| Test name | **Unmanned Aircraft General – Small (UAG)** |
| Questions | **60** scored multiple-choice (A/B/C). Unscored **validation** items may also appear; you cannot tell which; treat every item as scored. |
| Time | **2.0 hours** |
| Pass score | **70%** (at least **42 / 60** correct) |
| Min age to *take* the test | **14** (per FAA Testing Matrix) |
| Min age for the *certificate* | **16** |
| Authorization | **None** — no instructor endorsement for initial or retest |
| Fail → retest | **14 calendar days**; bring the failed Airman Knowledge Test Report (AKTR) |
| Fee | Set by PSI at booking (commonly cited ~**$175**; confirm when you schedule) |
| What you get after pass | Printed **AKTR**; then apply in **IACRA** for the Remote Pilot certificate (TSA security vetting; temporary certificate after clearance) |

### High-level scheduling (IACRA → PSI)

1. Create an **IACRA** profile and get an **FAA Tracking Number (FTN)** before booking: [iacra.faa.gov](https://iacra.faa.gov/).
2. Schedule **UAG** at an FAA Knowledge Testing Center via **PSI**: [faa.psiexams.com](https://faa.psiexams.com/faa/login).
3. Sit the test → keep the **AKTR**.
4. In IACRA, start application type **Pilot → Remote Pilot**, enter the knowledge-test exam ID (can take up to ~48 hours to appear), submit, wait for TSA email, print temporary certificate, wait for plastic in the mail.

Official walkthrough: [Become a Certificated Remote Pilot](https://www.faa.gov/uas/commercial_operators/become_a_drone_pilot).

### What to bring / expect day-of

- **Government-issued photo ID** meeting FAA Testing Matrix rules (photo, signature, DOB; if PO Box mailing address, also a current residential address).
- **FTN** (know it; it is on your IACRA profile).
- Arrive early; phones / notes / smartwatches go in storage.
- Center provides: testing software, scratch paper, **FAA-CT-8080-2H** Airman Knowledge Testing Supplement (charts/figures), and typically a basic calculator if allowed under center policy.
- Acceptable personal aids are limited (simple aviation calculators, plotters, etc. — see ACS Appendix 2). Do **not** bring notes or phones into the seat.

## Official topic outline (what the FAA tests)

### ACS areas of operation (what can appear)

From **FAA-S-ACS-10B**, *Remote Pilot – Small Unmanned Aircraft Systems Airman Certification Standards* ([PDF](https://www.faa.gov/training_testing/testing/acs/uas_acs.pdf)):

| Area | Tasks / focus |
| --- | --- |
| **I. Regulations** | Part 107 general + operating rules, registration (Parts 47/48), certification, waivers, **operations over people**, **Remote ID (Part 89)** |
| **II. Airspace** | Classes A–G, special-use, TFRs/NOTAMs, authorizations for B/C/D and surface Class E |
| **III. Weather** | Sources (METARs/TAFs/briefings), effects on performance |
| **IV. Loading & performance** | Weight/CG, load factor, stalls, density altitude effects |
| **V. Operations** | Radio/CTAF, airport ops + chart reading, emergencies, ADM/CRM, physiology, maintenance/preflight |

FAA “Become a Drone Pilot” lists the same knowledge areas required by **14 CFR §107.73** (regulations, airspace, weather, loading, emergencies, CRM, radio, performance, drugs/alcohol, ADM, airport ops, maintenance/preflight, night).

### Blueprint weights (important: ACS table is outdated)

The ACS Appendix 1 table still shows:

| Topic | ACS % (obsolete for live scoring) |
| --- | --- |
| Regulations | 15–25% |
| Airspace & requirements | 15–25% |
| Weather | 11–16% |
| Loading & performance | 7–11% |
| Operations | 35–45% |

**FAA Airman Testing Community Advisory (August 2025)** states that as of **2025-09-29**, that ACS testing blueprint is **obsolete**. The live blueprint is in the **PSI UAG Applicant / Candidate Information Bulletin** (linked from FAA ATCA; open via [faa.psiexams.com](https://faa.psiexams.com/faa/login) / PSI True Talent). Topics themselves did **not** change — only weighting and question alignment.

Industry summaries of the **current PSI bulletin** (verify in the bulletin itself before you sit):

| Content area | Approx. current share |
| --- | --- |
| Regulations | ~**48%** |
| Airspace classification & operating requirements | ~**20%** |
| Operations (incl. ADM) | ~**25%** |
| Weather | ~**5%** |
| Loading & performance | ~**2%** |

**Study implication:** spend the most time on **Part 107 / 48 / 89 rules** and **reading sectional charts for airspace + 107.41 authorization**, not on memorizing weather trivia. Still learn enough weather/loading to not throw away free points — and for real flights.

### What actually shows up (practical)

**Regulations (biggest bucket now)**

- Remote PIC responsibility; VLOS; one aircraft at a time; right-of-way; no careless/reckless; alcohol/drugs.
- Limits: **100 mph** groundspeed, **400 ft AGL** (with structure exceptions), **3 SM** visibility, cloud clearances.
- Day / civil twilight / night (anti-collision lighting).
- Registration; Remote ID failure → land as soon as practicable; serial number on registration.
- Ops over people categories; Category 4 needs airworthiness certificate.
- Accident reporting thresholds; waivers vs authorizations; moving-vehicle rules.

**Airspace & charts**

- Identify Class B / C / D / E / G and special-use (MOA, restricted, prohibited, MTR “VR/IR”) on a **sectional**.
- **§107.41:** prior ATC authorization for B, C, D, and surface Class E designated for an airport. Class G: no ATC auth required under 107.
- NOTAMs / TFRs; Chart Supplement for airport detail; CTAF frequencies from chart legends.
- From ~**2026-10-26/27**, FAA/PSI plan **embedded chart images** that may **not** be the fixed supplement figures — practice *reading* charts, not memorizing figure numbers.

**LAANC / authorizations (ops + exam awareness)**

- Controlled airspace needs **authorization** (LAANC or DroneZone / facility process). Exam language often says “ATC authorization,” not “LAANC app.”
- LAANC is how you get near-real-time low-altitude authorizations in participating airspace — critical for **Seattle / Sea-Tac Class B** ops, but the test cares about the **rule**, not the brand name.

**Operations / ADM / radio / emergencies / physiology**

- Hazardous attitudes (macho, impulsivity, invulnerability, resignation, anti-authority); CRM across **all** phases; IMSAFE / risk management.
- CTAF pattern language (downwind / base / final relative to runway).
- Deviation for emergency; report to FAA **upon request**.
- Fatigue, alcohol effects, night vision (~30 min dark adaptation).
- Preflight (§107.49): environment, people, weather, control link, power, brief participants.
- Maintenance when manufacturer has no schedule; PIC decides airworthiness.

**Weather & loading (small %; still fair game)**

- METAR decode; stable vs unstable air; density altitude → propeller efficiency.
- Load factor in turns; critical angle of attack → stall; follow loading instructions in the UAS flight manual / POH-equivalent.

### WA / Seattle notes (ops vs exam)

| Topic | On the UAG test? | For listing jobs? |
| --- | --- | --- |
| **Sea-Tac Class B** airspace + need for authorization | **Yes** (as Class B / chart / 107.41 concepts) | **Yes** — use LAANC (or equivalent) before flying |

## 1–2 week study plan (5–9pm + weekends)

**Budget:** about **15–25 focused hours** total (roughly **8–12 evenings** at 1.5–2 hours, or a tighter **~15 hour** sprint if you already read charts). Aim to schedule the exam near the end of week 1 or early week 2 once practice scores are stable **≥80%**.

### Week 1 — build the core

| Day | Block (pick 5–9 slots) | Do this |
| --- | --- | --- |
| **Mon** | 90–120 min | Create IACRA FTN. Skim ACS Areas I–V. Read [Become a Drone Pilot](https://www.faa.gov/uas/commercial_operators/become_a_drone_pilot). Download ACS + Study Guide + Supplement. |
| **Tue** | 90–120 min | **Regulations deep dive:** eCFR Part 107 + key Part 48 / Part 89 Remote ID points. Flash: altitude, speed, visibility, cloud, VLOS, twilight/night. |
| **Wed** | 90–120 min | **Sectional charts:** legend, airspace floors/ceilings (MSL vs AGL), MOA/MTR, obstacles. Work FAA sample chart questions with FAA-CT-8080-2H open. |
| **Thu** | 90–120 min | Airspace authorizations (107.41), NOTAMs/TFRs, Chart Supplement, CTAF. Open free LAANC-capable app and practice *looking up* a Seattle-area Class B grid (ops skill). |
| **Fri** | 60–90 min | Weather + loading: METARs, density altitude, load factor, CG. Light night — do not over-invest vs regulations/charts. |
| **Sat** | 2–3 hr | Full **PSI sample test** + FAA UAG sample PDF. Log every miss by ACS code. |
| **Sun** | 2 hr | Remediate misses. Read AC 107-2A sections that match your weak codes. Optional: cheap commercial practice set (see below). |

### Week 2 — harden and sit

| Day | Block | Do this |
| --- | --- | --- |
| **Mon** | 90 min | Operations / ADM / emergencies / physiology / maintenance review. |
| **Tue** | 90–120 min | Second full-length practice (different bank or reshuffle). Target ≥80%. |
| **Wed** | 60–90 min | Chart-only drill on **unfamiliar** sectionals (Aeronautical Chart User’s Guide + random chart excerpts). |
| **Thu** | 60 min | Light regs review; sleep. Or sit the test if booked. |
| **Fri–Sun** | Exam window | Sit **UAG**. Same day: start IACRA certificate application when AKTR ID appears. |

If Trust evenings steal Mon–Thu, compress week 1 into **Wed–Sun** and keep the **≥80% practice** gate before paying PSI.

## Day-of tips

1. **Eat and sleep**; 70% is the pass line — do not show up depleted.
2. Use the **tutorial** before the scored clock if offered.
3. For chart items: read the **question first**, then find the area; watch **MSL vs AGL** and shelf floors.
4. Flag hard items and move on; return with remaining time.
5. Unscored validation items look identical — answer them carefully.
6. After pass: photograph/keep the **AKTR**; start IACRA the same day if the exam ID is available.
7. After fail: calendar the **14-day** wait; study the ACS codes printed on the AKTR only.
